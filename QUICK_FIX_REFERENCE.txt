# QUICK REFERENCE - ROUTE BUG FIX

## The Problem
Frontend showing "Road cannot be calculated" error even though backend works

## The Root Cause
Frontend NOT passing congested roads to backend via `avoid` parameter

## The Fix
Updated `handleSearch()` in `src/App.jsx` to include `congestedRoads` in request URL

## What Changed
```javascript
// BEFORE (BROKEN)
fetch(`${API_BASE_URL}/api/route?from=${start}&to=${target}`)

// AFTER (FIXED)
let url = `${API_BASE_URL}/api/route?from=${start}&to=${target}`;
if (congestedRoads && congestedRoads.length > 0) {
  url += `&avoid=${congestedRoads.join(',')}`;
}
fetch(url);
```
